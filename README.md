# Peel & Co. — EcoDye Fruit Peel Poster Paint

> Hand-crafted organic poster paint made from upcycled fruit peels. Turns peels that would be thrown away into 12 bright, velvety opaque colors.

## Features
- **Hero Video Showcase**: Embedded autoplaying inline product showcase video.
- **Color Studio**: Interactive swatches and digital canvas drawing pad.
- **Market & Collection**: Full 12-color Studio Box and single tube selection.
- **Smart Checkout**: Multi-step checkout with delivery location picker and order summary.
- **Ambient Soundtrack**: Integrated background audio player with volume slider controls.
- **Artistic Sunset Aesthetic**: Responsive painterly sunset beach backdrop.
